# Markendateien

Hier liegen später Logo und Icon. Fehlt eine Datei, nutzt Schnippo den Platzhalter (`packaging/icon.png`), es gibt keinen Fehler. Die Pfade stehen zentral in `src/schnippo/branding.py`.

| Datei | Größe | Verwendung |
|---|---|---|
| `icon.png` | 512 × 512, quadratisch, transparent | `.mcpb`, Plugin, Karten |
| `logo.svg` | Vektor, für helle Flächen | README, Website |
| `logo-dark.svg` | Vektor, für dunkle Flächen | README im Dark Mode, Website |
| `social-preview.png` | 1280 × 640 | Vorschau auf GitHub und in sozialen Medien |

Keine Blackmagic-Logos und keine Anlehnung an das Resolve-Logo.
