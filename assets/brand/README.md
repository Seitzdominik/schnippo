# Markendateien

Originale vom Inhaber: `Schnippo Logo Icon.svg`, `Schnippo Logo Icon.png`, `Schnippo Logo.svg`. Sie bleiben unverändert. Alles andere erzeugt `tools/make_brand.py` daraus.

| Datei | Größe | Verwendung |
|---|---|---|
| `icon.png` | 512 × 512, quadratisch, transparent | `.mcpb`, Plugin, Karten |
| `logo.svg` | Vektor, für helle Flächen (Violett auf Weiß 5,7:1) | README, Website |
| `logo-dark.svg` | Vektor, für dunkle Flächen (helleres Violett `#A78BFA`, 6,0:1 auf Anthrazit) | README im Dark Mode, Website |
| `social-preview.png` | 1280 × 640 | Vorschau auf GitHub und in sozialen Medien |
| `preview-sizes.png` | Kontaktblatt | Prüfung bei 16, 32 und 64 px |

Farben: Violett `#7C3AED`, Violett hell `#8B47FF`, Anthrazit `#202020`. Sie gelten für Schnippos eigene Oberfläche. Die Design-Tokens für Motion Graphics gehören dem Nutzer und seinen Kunden; Schnippo-Violett ist dort nur das Beispiel, bis eine eigene Marke eingerichtet ist.
